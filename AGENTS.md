# IdleQuest Agent Guide
Read `PROJECT_SPEC.md` before changing the project. Keep scenario content separate from the plain-TypeScript game engine and prefer simple architecture. v0.x must remain mobile-first, static, and backend-free unless explicitly directed otherwise. Never silently change the scenario or persistence schema; document schema changes and add migrations for stored data. Keep incidents technically realistic. After significant decisions update `docs/architecture.md`. Before finishing, run `npm run lint`, `npm run typecheck`, `npm test`, `npm run validate:content`, and `npm run build`.
