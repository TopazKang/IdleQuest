# Roadmap

## v0.1 (current)
Five handcrafted incidents, mobile run loop, four-dimensional review, local history, validation, PWA basics, and Pages automation.

## Recommended next
1. Add seeded metric/modifier variation and compatibility-validated reusable incident components.
2. Add a compact history detail view with per-skill game-performance summaries and replay.
3. Test content with players, then deepen branches and distinct recovery states before adding Growth/Learn modes.

Later milestones may add profiles and hints, then dynamic secondary failures. Backend or AI belongs only after non-AI play is proven.
